# Patente legendaria

Creada con la herramienta integrada ImageGen, usando el marco épico existente
como referencia de composición. No se utilizó la API ni el modo CLI.

Archivo integrado: `src/main/resources/static/assets/Tesis-assets/cartas/patente_legendaria.png`.
La imagen contiene la ilustración y el marco; el nombre, los valores y el ingreso
se superponen mediante HTML para conservar los datos del motor como fuente de verdad.
Patente es la única carta con la categoría legendaria.
