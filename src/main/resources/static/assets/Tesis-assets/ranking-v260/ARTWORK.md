# Ilustración del ranking

`ranking-library.webp`: fondo original generado con la herramienta ImageGen el 2026-10-07 para la referencia de Ranking Global facilitada por el usuario. Biblioteca gótica, noche azul y luna, libros, velas y esfera armilar; sin texto ni controles incrustados. PNG original conservado en el directorio de imágenes generadas de Codex; producción WebP calidad90.

Insignias visibles reutilizan los PNG originales de `Rango-Niveles`; marcos, iconos y controles son HTML/CSS/SVG. No se sustituyen los assets de rango del usuario.
